# Mohanned Al Alshaikh Portfolio

Static portfolio website for Mohanned Al Alshaikh, Data and Business Intelligence Analyst.

## Local preview

Run a local server from this directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

This repository is designed to be published from the `main` branch root at:

`https://mohanned-alshaikh.github.io`

The repository contains only portfolio-safe screenshots, written case studies, and the public résumé. It does not include Power BI source files, private datasets, connection paths, or operational data.
